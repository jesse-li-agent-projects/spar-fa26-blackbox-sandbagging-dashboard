# Black-box sandbagging detection: dashboard

Static dashboard of the results of the SPAR FA26 black-box sandbagging detection project:
detectors × model-organism sets, an accuracy page, and sample transcripts.

Published with GitHub Pages from the root of the `main` branch of this repository.

This repository contains **only the built site**. It is generated and force-pushed as a single
commit by the project's private repository (the page footer names the source commit), so it has no
history; do not edit it by hand. See `NOTICE.md` for third-party notices.
